Enumerated values

brille._brille uses a number of enumerated values to control its behaviour and convey information.

class brille._brille.AngleUnit(self: brille._brille.AngleUnit, value: int)

The units of a number representing an angle.

>>> from brille import AngleUnit
>>> r = AngleUnit.radian

Members:

not_provided : unknown, will be inferred

radian : radian

degree : degree

pi : radian divided by pi

property name
class brille._brille.LengthUnit(self: brille._brille.LengthUnit, value: int)

The units of a number representing a length.

>>> from brille import LengthUnit
>>> a = LengthUnit.angstrom

Members:

none : A default value, the used value may be inferred

angstrom : 10-10 meter

inverse_angstrom : 1 / angstrom

real_lattice : fractional coordinates of real lattice

reciprocal_lattice : fractional coordinates of reciprocal lattice

property name
class brille._brille.NodeType(self: brille._brille.NodeType, value: int)

An enumeration to differentiate between Node types of the brille._brille.BZTrellisQdd, brille._brille.BZTrellisQdc, and brille._brille.BZTrellisQcc, classes.

The return type of the methods, e.g., node_at_type(), node_containing_type(), and all_node_types().

>>> from brill import NodeType
>>> nt = NodeType.polygon

Members:

assumed_null : Indicates a node which should be null but no explicit check was performed

found_null : A node which an explicit check found to be null

null : A null node

cube : A cube shaped node

polygon : A convex polygon shaped node
